# Bag screenshots inbox

Drop bag screenshots here: the Resources and Speedups lists, items (Mythic Gear, Mithril, Threads, Designs, shards, hammers…), pet items, Truegold.
GitHub app → this folder → Add file → Upload files (as many as you like).
Then tell Claude "uploaded". Claude reads them, updates the bag in the console and clears this folder.

Note: this repository is public — anything uploaded here can be seen by anyone until it's cleared.
