# Fonts

Self-hosted so the app paints without waiting for Google Fonts and works offline.

- `inter-latin.woff2`: Inter (variable, weights 400–700, Latin subset). © The Inter Project Authors. SIL Open Font License 1.1 (see `OFL-Inter.txt`).
- `cinzel-latin.woff2`: Cinzel (variable, weights 700–900, Latin subset), used for the brand name only. © Natanael Gama. SIL Open Font License 1.1.

Both files come from Google Fonts.
