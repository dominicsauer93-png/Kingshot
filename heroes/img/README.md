# Hero portraits

96×96 WebP crops of each hero card from the in-game hero list (your own screenshots, 11 Nov 2026). Used as avatars by `heroAv()` in `js/rally.js`; file name = hero name in lower case with spaces and "&" turned into "-" (e.g. `wee-woo.webp`). A hero without a file shows a letter tile instead.
